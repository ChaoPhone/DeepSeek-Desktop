## 为什么做这个？

API 费用太贵？想同时用多个 AI？

这个悬浮球直接打开 AI 网页版，**免费、无限制、不用 API**。悬停展开副球，一键切换 DeepSeek、ChatGPT、Gemini、智谱 GLM。

---

## 功能

- **多 AI 支持** - DeepSeek、ChatGPT、Gemini、智谱 GLM，悬停展开副球选择
- **悬浮球** - 想放哪里放哪里，拖拽就行
- **一键打开** - 点击直接进入 AI Chat
- **自定义外观** - 颜色、大小、透明度随你调
- **开机自启** - 开机就等着你用
- **多窗口** - 想开几个对话都行
- **任务栏区分** - 不同 AI 显示不同图标

npm run build    # 打包 exe
