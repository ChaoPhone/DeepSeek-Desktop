## 为什么做这个？

API 费用太贵？豆包太好用但想用 DeepSeek？

这个悬浮球直接打开 DeepSeek Chat 网页版，**免费、无限制、不用 API**。就像豆包一样，点一下就能聊，拖到哪里都行。

---

## 功能

- **悬浮球** - 想放哪里放哪里，拖拽就行
- **一键打开** - 点击直接进入 DeepSeek Chat
- **自定义外观** - 颜色、大小、透明度随你调
- **开机自启** - 开机就等着你用
- **多窗口** - 想开几个对话都行

## 开发

```bash
git clone https://github.com/ChaoPhone/DeepSeek-Desktop.git
cd DeepSeek-Desktop
npm install
npm start        # 开发运行
npm run build    # 打包 exe
```
